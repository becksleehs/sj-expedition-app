승주 원정대 FRESH v1.7 - UNIFIED ARCADE CHARACTER SYSTEM

핵심 변경
- 기존 PNG 캐릭터 + SVG 스티커형 장비 오버레이 방식 폐기
- 남 3 / 여 3 캐릭터를 동일 SVG 좌표계에서 실시간 렌더링
- 캐릭터 선택, 학생 메인, 홈 캐릭터, 장비실 모두 동일 렌더러 사용
- 장비: 탐험 모자, 탐험복, 스카프, 가방, 탐험 신발, 카메라, 나침반, 망원경, 태극기, 배지
- 착용 장비는 동시에 조합 가능
- 카메라/나침반/망원경/태극기는 도구 슬롯으로 1개만 활성화
- 같은 아이템을 다시 누르면 해제
- 기존 장비 상태는 v1.7 최초 실행 시 1회 초기화

확인 순서
학생 선택 -> 캐릭터 선택 -> 홈 -> 장비실 -> 탐험복/모자/스카프/가방 -> 도구 하나 -> 완료 -> 홈
