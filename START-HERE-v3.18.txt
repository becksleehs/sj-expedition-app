승주 원정대 FRESH v3.18 — 전체 GitHub 업로드용
================================================
이 ZIP은 캐릭터 확인용이 아니라 전체 앱 통합본입니다.
예전에 받은 v3.17 캐릭터 확인용 ZIP을 올릴 필요가 없습니다.

[GitHub Desktop 업로드 순서]
1. 다운로드한 ZIP의 압축을 풉니다.
2. GitHub Desktop에서 sj-expedition-app 저장소를 선택합니다.
3. Repository > Show in Explorer로 기존 저장소 폴더를 엽니다.
4. 압축을 푼 폴더 안의 전체 파일과 폴더를 기존 저장소 폴더에 복사합니다.
   같은 이름이 있으면 덮어쓰기 합니다.
   index.html, package.json, netlify.toml, assets, css, js, netlify가
   기존 저장소의 같은 위치에 있어야 합니다. 새 하위 폴더를 만들지 마세요.
   ZIP 파일 자체를 저장소에 올리는 것이 아닙니다.
5. Summary에 아래 문구를 입력합니다.
   FRESH v3.18 캐릭터 65단계·미션 자동 XP·동영상 앨범·교사모드 통합
6. Commit to main(현재 브랜치) > Push origin을 누릅니다.
7. 연결된 Netlify 사이트의 배포 완료를 확인하고 휴대폰에서 새로고침합니다.

[처음 한 번: 기존 테스트 자료 정리]
- 메인 톱니바퀴를 3초 누르면 관리자 페이지로 이동합니다.
- 기존 교사 PIN으로 로그인합니다. 이번 버전은 PIN을 변경하지 않습니다.
- '공지 · 채팅 · 앨범 관리' > '시작 준비 초기화'를 누릅니다.
- 확인창에서 진행하면 기본 공지 1개를 남기고 기존 채팅·고정글·일반 앨범의
  사진과 동영상을 삭제합니다. 삭제한 자료는 되돌릴 수 없습니다.
- 학생 계정·경험치·성장 단계·미션 제출물은 유지합니다.
- 이후 공지는 관리자에서 등록·삭제할 수 있고 기존 글이 계속 남습니다.
- 조 배정만 비우려면 '조편성 초기화'를 사용하세요.

[미션 운영 순서]
1. 관리자에서 참석 학생을 체크합니다.
2. 자동 편성 > 미리보기 확인 > 조편성 확정을 누릅니다.
3. 장소별 미션 목록에서 원하는 미션을 체크하고 '체크한 미션 시작'을 누릅니다.
4. 학생은 열린 미션만 봅니다. 조별/학년별 미션은 대표 1명이 제출합니다.
5. 정상 제출하면 시작 당시 참여 명단의 학생에게 각각 20 XP가 자동 지급됩니다.
6. 같은 미션을 중복 제출하거나 재시도해도 경험치는 한 번만 지급됩니다.
7. '체크한 미션 종료'를 누르면 활동 목록에서 숨겨집니다.
   이미 제출한 내용은 학생의 '앨범 > 미션 제출함'에 계속 남습니다.
8. 재편성 후 새 미션을 시작하면 새 조가 반영됩니다.
   이미 시작한 미션을 다시 열면 기존 참여 명단과 제출 기록을 유지합니다.

[앨범과 동영상]
- 사진 / 동영상 / 미션 제출함, 세 폴더로 구분합니다.
- 사진과 동영상은 파일을 선택하고 업로드 버튼을 누릅니다.
- 동영상: 3분 이내, 파일당 150MB(150 MiB) 이하.
- MP4 권장. MOV·WebM은 사용 기기가 해당 영상 형식을 재생할 수 있어야 합니다.
- 3분 영상이라도 용량이 넘으면 해상도나 화질을 낮추어 저장해주세요.
- 영상은 작은 부분으로 나누어 전송하며 진행률을 표시합니다.
- 업로드 중 화면을 열어 두세요. 연결 오류가 나면 같은 화면에서 다시 누르면
  완료된 부분 다음부터 재시도합니다. 앱을 닫은 뒤 이어 올리기는 지원하지 않습니다.
- 일반 앨범에 올리는 것만으로 XP가 생기지 않습니다.
- 보상 대상 파일은 미션 탭의 '미션 제출하기'로 올려야 합니다.
- 교사의 파일 등록·삭제·일반 앨범 초기화는 관리자 화면에서 합니다.
- 미션 제출물 삭제는 관리자 미션 목록에서 하며 이미 지급한 XP는 유지됩니다.
- 장시간 실패하고 버려진 업로드는 서버에 일부가 남을 수 있습니다.
  Netlify 저장공간·요청 사용량은 운영 중 확인해주세요.

[함께 반영한 사항]
- 학생 13명 × 성장 5단계(65개 모습), 홈·조편성·성장 화면 연결.
- 김서하 피부톤 완화, 승인한 세 학생 특징 유지, 다른 9명 개성 강화.
- 모바일 지도 전체 표시, 학생과 작은 원정대 깃발이 잘리지 않는 배치.
- 홈 하단 카드는 작게, 나의 캐릭터와 성장 로드맵은 전신 표시.
- 조별 캐릭터를 가로로 배치하고 이름은 아래에 표시.
- 메인 명칭 '원정 미션', 별도 돌발 안내 알림 유지.
- 공지 누적·등록·삭제, 채팅방 청소·중요사항 상단 고정.
- 한국 시간 시계를 기준으로 진행 중인 일정 칸 강조.
- 우측 상단 메뉴의 '오늘 하루는 어땠나요?'에 2~3줄 소감.
  하루 최초 저장 보상 10 XP, 같은 날 수정은 중복 보상 없음.
- '학생이 아닙니다' 선택을 브라우저에 유지. 일반 교사는 탭 이동 후에도
  학생 선택 화면으로 돌아가지 않고 공지·일정·열린 미션·채팅을 열람합니다.
- 일반 교사 열람 모드는 관리자 권한을 주지 않습니다.
- 실제 학생 선택은 '학생으로 시작하기'를 눌렀을 때만 진행합니다.
