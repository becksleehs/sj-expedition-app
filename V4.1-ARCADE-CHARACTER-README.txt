승주 원정대 v4.1 아케이드 아바타 + 장비 시스템

이번 버전에서 실제로 교체된 부분
1. 기존 단순 캐릭터 SVG 6종을 같은 341x512 좌표계의 아케이드풍 탐험가 아바타로 교체.
2. 얼굴/머리/몸/팔/신발의 비율을 통일해 아이템이 캐릭터에서 떠 보이는 현상을 줄임.
3. 탐험복·가방·모자·스카프·카메라·나침반·배지·망원경을 같은 좌표계로 다시 제작.
4. 같은 장비를 다시 누르면 장착/해제 토글.
5. 장착된 장비는 색상 버튼으로 5가지 색상 중 선택 가능하며 학생별로 저장.
6. 캐릭터 선택 확인창에서 '예'를 누르면 학생 메인 화면으로 이동.
7. 기존 학생/미션/퀴즈/모험지도 기능은 유지.
8. 이전 sj17Avatar 값이 남아 있어도 현재 캐릭터 상태로 자동 이전.
9. 서비스워커 캐시 버전을 올려 이전 캐릭터 파일이 남아 보이는 문제를 줄임.

GitHub Desktop
- 압축을 풀고 sj-expedition-app 폴더 안의 파일을 기존 저장소 폴더에 덮어쓰기
- GitHub Desktop → Changes에서 변경 파일 확인
- Summary: v4.1 Arcade Avatar & Gear System
- Commit to main
- Push origin
- GitHub Pages에서 확인할 때 Ctrl+Shift+R

주의
- 압축 파일 자체(js.zip 등)는 기존 저장소에 남겨도 됩니다. 이번 버전은 실제 js/*.js와 assets/chibi-v4, assets/chibi-gear-v4 파일을 수정합니다.
- 웹에서 이전 캐릭터가 계속 보이면 서비스워커/브라우저 캐시가 남은 경우가 있으므로 Ctrl+Shift+R 후 다시 확인하세요.
