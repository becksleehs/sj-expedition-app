승주 원정대 v4.0 캐릭터 시스템 교체

이번 버전 핵심
1. 기존 일러스트 위에 아이템을 억지로 덧씌우는 방식을 제거했습니다.
2. 모든 캐릭터를 동일한 341x512 좌표계의 2~2.5등신 chibi 캐릭터로 통일했습니다.
3. 가방/탐험복/모자/스카프/카메라/나침반/배지/망원경을 동일 좌표계의 전용 레이어로 제작했습니다.
4. 장착/해제는 같은 아이템을 다시 누르면 토글됩니다.
5. 장착된 아이템만 색상 선택이 가능하며 색상도 학생별로 저장됩니다.
6. 캐릭터 선택 확인 후 '예'를 누르면 학생 메인화면으로 이동합니다.
7. 부산 롯데월드-울릉도-독도 원정용 기존 미션/퀴즈 구조는 유지합니다.
