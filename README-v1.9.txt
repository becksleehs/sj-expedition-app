승주 원정대 FRESH v1.9 — 실사용 캐릭터 자산 개선

- 캐릭터 이미지에 박혀 있던 기본형/모자/신발 등의 글자 제거
- 6명 x 15개 상태를 PNG로 다시 추출/정리 (90개)
- JPG 대신 투명 PNG, 확대 표시 및 선명도 개선
- 장비 클릭 시 매번 캐릭터 사진이 실제 다른 상태 이미지로 전환
- 0개/단일 장비/대표 2개 조합은 해당 완성 이미지 사용
- 3개 이상은 완전장착 이미지를 사용하고 선택 장비 아이콘을 함께 표시
- 캐릭터 선택/홈/장비실이 같은 v1.9 PNG 자산을 사용

주의: 모든 10개 아이템의 1024개 조합을 각각 별도 일러스트로 만든 버전은 아닙니다. 현재는 실제 사용 가능한 15개 완성 상태를 기반으로 안정적으로 전환합니다.
