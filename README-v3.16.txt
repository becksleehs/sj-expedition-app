FRESH v3.16 조편성 초기화 및 장소별 미션 운영

관리자 로그인 → 장소별 원정대 미션:
1. 참석자를 반영한 조편성을 먼저 확정합니다.
2. 미리 작성된 미션을 체크하고 선택 미션 시작을 누릅니다.
3. 학생 하단 미션 탭에서 공개 미션을 확인하고 사진 또는 글을 제출합니다.
4. 관리자는 각 미션 아래 제출 확인에서 글·사진을 확인합니다.
5. 선택 미션 종료로 제출을 닫고, 시작으로 다시 열 수 있습니다.
조편성 초기화는 현재 배정만 지우며 기존 미션 명단·제출물·XP는 유지합니다.
미션 재공개는 기존 미션을 재개하며 새 조로 중복 보상을 만들지 않습니다.

포함 미션: 롯데월드 조별사진·학년사진·조 소개, 독도 입도사진·소감,
추산 메가 울라포토존 사진, 관음도 단체사진, 해양생태관 소감,
봉래폭포 학년사진, 후배 추천 장소, 3학년 단체사진·미래 랜덤 편지.
랜덤 편지: 시작 당시 참석한 3학년끼리 한 통씩, 자신을 제외하여 배정합니다.
미달성 미션은 기본 비공개입니다. 독도 입도가 불가능하면 입도사진 미션을 열지 마세요.

미션별 보상은 20 XP. 조별·학년별은 대표 1명이 제출한 뒤 구성원 각자
해당 미션의 완료 · 경험치 받기를 누르면 한 번씩 지급됩니다.
사진은 미션 제출물로 저장되며 일반 앨범에 자동 복제하지 않습니다.
편지는 제출자와 관리자만 내용을 확인합니다. 친구에게 전달하는 과정은 교사가 진행합니다.

설치: ZIP 내용 전체를 기존 폴더에 덮어쓰기 → Commit → Push origin.
