승주 원정대 FRESH v3.19 전체 업로드용

이 ZIP은 v3.18 전체 앱과 캐릭터 13명 × 5단계, 동영상·미션 기능을 포함합니다.
압축을 푼 뒤 내용물을 기존 GitHub 저장소 폴더에 덮어쓰세요.
ZIP 파일 자체를 저장소에 올리지 마세요. index.html과 netlify.toml이 저장소 최상단에 있어야 합니다.
GitHub Desktop에서 변경 내용을 확인하고 아래 Summary로 Commit 후 Push하세요.
Netlify 배포 완료 후 모바일에서 새로고침하세요.

Summary:
FRESH v3.19 통합본: 섬별 퀴즈·캐릭터 선택·조별/학년별 미션·돌발미션 반영

새 기능
1. 울릉도 이야기 5개 / 퀴즈 5문제, 독도 이야기 5개 / 퀴즈 5문제.
2. 관리자 > 학습 콘텐츠 공개에서 네 항목을 각각 열고 닫습니다.
   울릉도행 배: 울릉도 이야기와 울릉도 퀴즈를 열기.
   독도 방문 전: 독도 이야기와 독도 퀴즈를 열기.
   배포 후 새 네 항목은 기본 잠김입니다. 기존 통합 공개 상태는 승계하지 않습니다.
3. 답안을 누르면 첫 답안이 서버에 확정됩니다. 정답 10 XP, 오답 0 XP.
   다시 열기·새로고침·다른 기기에서도 재응시나 중복 보상이 되지 않습니다.
   섬별 최대 50 XP, 이야기 읽기는 각각 5 XP입니다. 기존 8문제 완주 보너스는 새로 지급하지 않습니다.
   이전 정답 보상과 경험치는 보존합니다. 이전에 보상받은 문항은 완료 처리합니다.
   이전 버전이 서버에 저장하지 않은 오답은 복원할 수 없습니다.
4. 자동 성장 안내는 홈에서만 표시합니다. 퀴즈·사진 업로드 중에는 표시하지 않습니다.
   나중에를 누르면 같은 홈 방문에서는 다시 묻지 않으며 다음 홈 방문에서 다시 안내합니다.
5. 나의 성장에서 달성한 캐릭터 사진 또는 '이 모습 선택' 버튼을 누르세요.
   1단계 모습으로 돌아가도 획득 XP와 성장 단계는 줄어들지 않습니다.

장소별 원정미션 최종 수정 반영 (총 15개)
- 장소 안에서 조별 / 학년별 / 개인 미션을 구분하여 표시합니다.
- 우리 조 소개: 단체사진과 함께 조 이름·구호·소개 글을 제출합니다.
- 독도 조별 사진: 태극기, 독도 수호 포스터, 멋진 문구와 함께 촬영합니다.
- 해양생태관 개인 미션: 가장 인상 깊은 전시 사진 + 그 이유를 제출합니다.
- 친구 2~3명과 괭이갈매기 사진: 독도에서 하는 돌발미션, 경험치 0 XP.
- 그 외 미션은 기존대로 참여 단위에 따라 각 20 XP를 지급합니다.
- 모든 미션은 관리자가 공개해야 학생 화면에 나타납니다.

검증: 모의 저장소 기반 통합 테스트 17개 통과, JS와 HTML 내 스크립트 문법 검사 통과.
실제 Netlify 배포 및 휴대폰 화면·영상 재생 검증은 수행하지 않았습니다.
기존 공지·앨범·학생 데이터는 업로드만으로 초기화하지 않습니다.
