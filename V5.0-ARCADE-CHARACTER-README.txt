승주 원정대 v5.0 — 아케이드 아바타 시스템

이번 버전은 캐릭터와 장비를 '한 장의 그림에 장비를 덧씌우는 방식'에서 완전히 분리했습니다.
캐릭터와 장비가 동일한 SVG 좌표계 안에서 함께 그려지므로 모자·스카프·카메라·나침반·배지·망원경·가방·탐험복이 캐릭터 몸에 맞지 않게 떠다니는 문제가 생기지 않습니다.

주요 변경
1. 아케이드 게임 느낌의 아기자기한 캐릭터 6종
2. 장비 탈착: 장착된 장비를 다시 누르면 해제
3. 장비별 5가지 색상 선택
4. 캐릭터 선택 → 확인 팝업 → '예' → 학생 메인 화면 이동
5. 캐릭터 변경 시에도 같은 아바타 렌더러 사용
6. 메인/학생/꾸미기 화면의 캐릭터 표시를 동일한 시스템으로 통일
7. 서비스워커 캐시 버전을 v5.0으로 변경하여 이전 캐릭터 파일이 남는 문제 완화

주의
- 기존 localStorage의 학생 점수·미션·팀 정보는 유지됩니다.
- 캐릭터를 새로 선택하면 해당 학생의 기존 장비는 초기화하여 새 캐릭터와 함께 깨끗하게 시작합니다.
