1) 울릉도·독도 역사 이야기 화면 추가
   - 울릉도 4개 이야기 / 독도 4개 이야기
   - 국사편찬위원회, 조선왕조실록, 외교부 공개 사료 링크
   - 학생 로그인 상태에서 이야기 1개 읽기 완료 시 +5 XP (각 1회)

4) 홈/성장 UI 보정
   - 나의 캐릭터 카드에서 전신이 보이도록 축소 표시

   - 승주원정대 깃발은 실제 승주중 로고 파일을 한 번만 표시하는 HTML 오버레이로 교체
5) 기존 기능 유지
   - 학생 13명 / 5단계 성장 캐릭터 65장
   - 학생 비밀번호 / 교사 초기화 / 스페셜 미션 / 온라인 채팅 / 일정 DAY 탭
