변경 사항
- 하단 배지 메뉴를 역사·퀴즈로 교체. 역사와 퀴즈는 새 이동 중 역사 미션 화면에서 섬별로 이동.
- 홈의 원정 미션은 현장 미션 전용 화면으로 바로 연결.
- 미션 홈 카드 조회를 학생 인증 처리와 분리하여 독립적으로 갱신.
- 공개된 현장 미션만 학생에게 표시. 홈은 5초, 미션 목록은 작성 중이 아닐 때 10초마다 갱신.
- 관리자 시작 후 서버 공개 상태를 다시 확인하고 성공/실패를 표시.
- 조편성이 아직 확정되지 않았다면 관리자에서 출석 반영 → 조편성 확정 → 미션 선택 → 시작 순서로 진행.
- 기존 v3.19 캐릭터, 섬별 퀴즈, 15개 미션, 동영상, 괭이갈매기 돌발미션 0 XP 등 모두 유지.

검증: 통합 테스트 18개 및 스크립트 문법 확인. 실제 배포 서버와 휴대폰에서의 재현 검증은 미실시.
