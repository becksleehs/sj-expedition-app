승주 원정대 FRESH v2.0 - 2D 아바타 시스템

핵심 변경
- 기존 사진 교체 방식 제거
- 6종 캐릭터를 동일한 2D 아바타 좌표계로 통일
- 모든 장비를 독립 레이어로 실시간 장착/해제
- 여러 아이템 동시 착용 가능
- 캐릭터 선택 / 홈 / 학생 메인 / 장비실 동일 렌더러 사용
- 확대해도 흐려지지 않는 SVG 기반
- 이미지 안에 '기본형/모자/신발' 같은 글자가 박히는 문제 제거

확인 순서
학생 선택 -> 캐릭터 선택 -> 장비실 -> 탐험복/모자/스카프/가방/신발/카메라/망원경/나침반/태극기/배지 복수 선택 -> 홈 확인
