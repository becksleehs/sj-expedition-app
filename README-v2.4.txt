승주 원정대 FRESH v2.4 EXACT PRESET

핵심 변경
1) 승인한 '승주 원정대 2D 아바타 프리셋 시트'를 실제 웹 자산의 원본으로 사용합니다.
2) 캐릭터 선택 / 장비 꾸미기 / 홈 / 학생 메인 모두 js/avatar-gear.js 한 렌더러를 사용합니다.
3) 웹에서 별도의 단순 SVG 캐릭터를 다시 그리지 않습니다.
4) 장비 화면은 원본 시트에 실제 존재하는 9개 프리셋을 그대로 보여주는 안정판입니다.
   - 기본형 / 탐험 모자 / 스카프 / 탐험복 / 탐험복+모자 / 카메라 / 망원경 / 배지(태극기) / 조합 예시
5) 같은 프리셋을 다시 누르면 기본형으로 돌아갑니다.

주의
- 이 버전은 '화면 일치'를 우선하여 임의의 무한 조합 레이어가 아니라, 승인된 프리셋 이미지를 그대로 사용합니다.
