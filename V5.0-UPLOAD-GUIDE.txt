[GitHub Desktop 업로드]

1. 이 ZIP의 압축을 풉니다.
2. 압축을 푼 폴더 안의 파일을 기존 sj-expedition-app 저장소 폴더에 그대로 덮어씁니다.
   (sj-expedition-app 폴더 자체를 한 단계 더 만들지 마세요.)
3. GitHub Desktop을 열고 sj-expedition-app 저장소를 선택합니다.
4. 왼쪽 Changes에 변경된 파일이 나타나는지 확인합니다.
5. Summary에 다음처럼 입력합니다.
   v5.0 아케이드 캐릭터 시스템 완성
6. [Commit to main]을 누릅니다.
7. 위쪽 [Push origin]을 눌러 GitHub에 올립니다.
8. 웹사이트를 새로고침할 때 Ctrl+Shift+R을 눌러 캐시를 강제로 새로고침합니다.

중요
- js.zip 같은 ZIP 파일을 저장소에 넣는 것이 목적이 아닙니다.
- ZIP은 배포용 묶음 파일이고, GitHub에는 압축을 푼 실제 파일들이 들어가야 합니다.
- 기존 js.zip은 삭제해도 되고 남겨도 되지만, 사이트 동작에는 필요하지 않습니다.
