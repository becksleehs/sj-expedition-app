FRESH v3.15 현장 운영 관리와 하루 소감

배포: 압축 내용 전체를 기존 폴더에 덮어쓰기 → Commit → Push origin.
Summary: FRESH v3.15 공지·채팅·앨범 관리 및 일정 강조·하루 소감 추가

배포 후 관리자 로그인 → 공지 · 채팅 · 앨범 관리:
1. 기본 공지 1개만 남기기: 기존 공지를 지우고 환영·안전 안내 1개를 등록합니다.
2. 방 청소하기: 기존 메시지를 삭제합니다. 고정 중요사항은 유지됩니다.
3. 중요사항 고정 저장: 채팅방 맨 위에 표시합니다. 빈 내용 저장 시 해제됩니다.
4. 앨범 전체 초기화: 기존 사진과 설명을 삭제합니다.
5. 공지·사진 개별 삭제 및 교사 사진 등록을 지원합니다.
초기화는 확인창에서 승인한 뒤 수행합니다. 삭제는 복구할 수 없습니다.
ZIP 배포만으로 서버 기록을 자동 삭제하지 않습니다. 위 버튼을 관리자 화면에서 실행하세요.

일정: 기기의 시계를 한국 시간으로 표시합니다. 날짜·시간이 해당되는 일정에 테두리를 표시합니다.
자정을 넘는 선박 이동과 서로 겹치는 일정은 각 시간 구간을 기준으로 강조합니다.
우측 상단 메뉴 → 오늘 하루는 어땠나요?: 학생 로그인 후 2~3줄 작성.
한국 날짜별로 기록이 남고 하루 첫 기록에 +10 XP, 재저장 시 추가 지급하지 않습니다.
미션 명칭은 변경하지 않았습니다.

검증: 변경 스크립트 문법 및 모의 저장소에서 관리자 권한, 초기화, 개별 사진 삭제,
소감 저장·줄 수 확인·10 XP 지급·순차 재시도 중복 방지 테스트 통과.
실제 서버 및 휴대전화 화면 검증은 별도입니다.
