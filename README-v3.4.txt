승주 원정대 FRESH v3.4

주요 변경
1. 홈 카드: '오늘의 원정대 조편성'으로 변경.
2. 홈의 '오늘의 미션' 카드 -> 교사 전송형 '스페셜 미션' 카드.
3. 교사 관리자에서 스페셜 미션 입력/전송/종료.
4. 학생은 새 스페셜 미션을 최대 약 8초 안에 팝업으로 확인.
5. 학생이 브라우저 알림 권한을 허용한 경우 시스템 알림 표시(앱이 열려 있거나 백그라운드에 살아 있는 동안).
6. 채팅 입력창을 고정 하단 메뉴 바로 위에 항상 보이게 수정.
7. 채팅은 카카오톡 단체방처럼 새 메시지가 아래에 쌓이고 목록은 위로 스크롤됨. 최신 위치에 있으면 자동으로 맨 아래 이동.
8. 하단 메뉴 순서 고정: 홈 > 공지 > 일정 > 미션 > 채팅 > 배지 > 앨범.
9. 꾸미기 화면 캐릭터를 메인과 동일한 avatar-v33 원본으로 통일. 기존 avatar-v24 프리셋 자산 삭제.
10. 장비를 동일 720x900 좌표 레이어로 처리하여 캐릭터가 다른 그림으로 바뀌는 이질감 제거.

교사 관리자 진입
- 메인 왼쪽 위 설정(톱니) 버튼을 약 3초 길게 누름.
- 교사 PIN: 기존 설정 사용. 기본값 1014.

알림 참고
- 웹페이지가 열려 있거나 백그라운드에 살아 있는 경우 시스템 알림까지 표시할 수 있음.
- 브라우저/PWA가 완전히 종료된 상태에서도 즉시 푸시하려면 별도의 Web Push(VAPID) 서버 설정이 추가로 필요함.
